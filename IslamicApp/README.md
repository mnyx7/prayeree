# Islamic Companion iOS project

Open `IslamicApp.xcodeproj` in Xcode and select the `IslamicApp` scheme.

The current project documentation is maintained at the repository root:

- [README — features, setup, architecture, services, and release requirements](../README.md)
- [Privacy policy draft](../PRIVACY_POLICY.md)
- [Contact and support](../CONTACT.md)

The app targets iOS 17+ and uses Adhan Swift 1.5.0 through Swift Package Manager. `project.yml` is the XcodeGen specification for the included Xcode project.
